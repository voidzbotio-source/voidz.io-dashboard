Dashboard Login

Enter the code from your authenticator app, or one of your backup codes.

Locked out of 2FA?

If you set up a recovery email, we'll send a login code there — then type it in the box above.

No recovery email? Since you run the dashboard, you can get back in from the server:

1. In the dashboard's .env file, add DISABLE_2FA=true and restart it. You'll then log in with just your password.

2. Afterwards, open Settings → Account to set 2FA up again (scan a fresh QR), then remove that line and restart.

Alternatively, delete two-factor.json on the server and restart.

Stay logged in?

On this device you won't be asked for your authenticator code again for 72 hours (you'll still enter your password). After that, you'll re-authenticate.
